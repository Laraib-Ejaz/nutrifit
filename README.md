# 🏋️‍♂️ FitLife – AI Powered Fitness & Health Assistant

FitLife is an Android-based health and fitness application that helps users maintain a healthy lifestyle by providing BMI calculation, personalized workout plans, AI-powered chatbot support, hydration tracking, daily step counting, and customized diet plans based on BMI. It acts as your smart fitness trainer and daily health companion.

## 🧩 Modules & Functionality

### 🥗 Diet Plan Module
- API-based diet recommendations
- Personalized meals according to BMI
- Displays images using URL
- Helps maintain nutritious health routine

---

### 🏋 Workout Activity Module
- Suggests workouts via API based on BMI
- Displays animated exercise guidance
- Uses GIFs stored in Drawables
- Glide Library used for loading animations

---

### 🚶 Step Counter Module
- Uses device hardware motion sensor
- Tracks:
  ✔ Steps Walked  
  ✔ Calories Burned  
  ✔ Distance Covered  
- Auto daily updates
- Share progress option

---

### 💧 Hydration Activity Module
- Tracks daily water intake
- Separate hydration record for every user
- Updates every day
- Encourages hydration habit

---

### 🤖 AI Chatbot
- Powered by Gemini AI API
- Answers health & fitness queries
- Acts like a smart assistant

---

### 👤 Profile & Reminders
- Profile Management
- Logout
- Workout Reminders
- Hydration Reminders
- Implemented using Broadcast Receiver
